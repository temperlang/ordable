        Natural keys

        Click an Ordable row. Its natural key is a string that sorts by plain comparison exactly as the row sorts naturally. Code points in hex; 1 separates levels. A number goes in as its count of digits, then its digits, so 9 (one digit) comes before 10 (two), however they're written; the highlight marks where two keys first differ.

        Store naturalKey(name) in an indexed database column and ORDER BY it, with a binary collation: the same keys come from every language.

        Play with the API

        How it's made
        
      
        
        Ordable is written once, in
        Temper, a language built for
        writing libraries that compile to many other languages. Temper turns
        the same source into a natural library for each one: classes and
        methods in C# and Java, modules in Lua and Python, a crate in Rust,
        and so on. Tests run on every language, and every language sorts
        every list the same way.
      
        
      
        
        This page uses the JavaScript version directly, with no framework,
        bundled with esbuild. Much
        of its size is Unicode tables: digits in every script, case folding,
        and accented letters' base letters.
